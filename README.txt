# GarbageBot — сборка одного Windows EXE

Этот проект автоматически собирает `GarbageBot.exe` на GitHub Actions. В EXE включаются Python-зависимости и Tesseract OCR с языковыми данными. На целевом Windows-ПК ничего устанавливать не требуется.

## Как получить EXE
1. Создай бесплатный репозиторий на https://github.com/new.
2. Распакуй этот архив и загрузи **все файлы и папки**, включая скрытую папку `.github`, в репозиторий. Удобнее всего: `Add file` → `Upload files`.
3. Открой вкладку **Actions**. Если спросит, разреши запуск workflows.
4. Дождись зелёной галочки у `Build Windows EXE`.
5. Открой завершённый запуск и скачай артефакт **GarbageBot-Windows-EXE**. Внутри будет `GarbageBot.exe`.

## Управление в игре
- F6 — старт/стоп
- F7 — аварийная остановка (отпустить клавишу)
- F8 — пауза
- ESC — выход

Подойди к кучке мусора, запусти EXE и нажми F6. Для первого теста проверь распознавание на коротком участке.

## Настройка области экрана
Если буква не попадает в область распознавания, открой `garbage_bot.py` и настрой `ROI_X`, `ROI_Y`, `ROI_W`, `ROI_H`. Это доли ширины/высоты экрана. Для отладки включи `SHOW_DEBUG = True`.

## Ограничения
OCR зависит от разрешения, масштаба и контраста. Направления-стрелки могут требовать отдельной калибровки, если игра показывает их пиктограммами, а не текстовыми символами. Некоторые игры/серверы могут запрещать макросы; проверь правила сервера. Не используй скрипт в обход правил.
